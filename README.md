# daix-eth-volatility
DAIX (DeFi Activity IndeX): daily Fisher quantity index of 55.5M screened Uniswap V3 and Aave V3 events on Ethereum, 18 Jul 2025–1 Oct 2026, with ETH realised variance, protocol drivers, forecasts and test results for the paper on DAIX as a real-time measure of Ether volatility (Digital Finance, submitted).
